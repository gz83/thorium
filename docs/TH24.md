# Thorium 2024 UI

Chrome Refresh 2023 changed Chromium's top chrome, menus, controls, spacing,
colors, and shapes. Thorium 2024 UI (Th24) is an optional compatibility style
that restores selected pre-refresh density and visual conventions while
retaining Chromium's current architecture.

It does not attempt to restore an entire historical Chromium UI tree. Keeping
the implementation on current code paths reduces rebase risk and avoids
reviving removed security or platform behavior.

## Enable Th24

The feature is disabled by default. Enable it at:

```text
thorium://flags/#thorium-2024
```

`chrome://flags/#thorium-2024` remains compatible. The experiment can also be
shown through Chrome Labs. Restart the browser after changing the feature.

## Current scope

The core patch owns:

- the `Thorium2024` feature definition;
- native UI dimensions, spacing, colors, and shapes;
- translucent inactive horizontal tabs;
- selected older-style icons and folder imagery;
- flag-gated shared WebUI button, toggle, and select styling in Settings.

Closing the feature restores Chromium values at the modified native and
Settings WebUI call sites. Other WebUI surfaces do not automatically inherit
the Settings root attribute.

Several behaviors were intentionally split from the core patch so they can be
maintained independently:

- Sharing Hub page-action enablement;
- menu keyboard interactions and mnemonic visibility;
- classic Omnibox, rectangular tabs, and custom tab widths;
- Tab Search position and pinning.

Those features may have their own flags or command-line switches and should not
be treated as evidence that Th24 itself is enabled.

## Intentional Thorium behavior

Two owner decisions are preserved independently of Chrome Refresh defaults:

- the top-bar separator between the tab strip and Omnibox should not gain
  curved edge treatment;
- the horizontal Tab Strip Combo Button is on the physical right by default.

Users can enable
`thorium://flags/#left-aligned-tab-strip-combo-button` to place the entire
combo button on the physical left, including in RTL layouts. Chromium removed
the former standalone Tab Search button, so this flag controls the unified
combo button that contains Tab Search.
